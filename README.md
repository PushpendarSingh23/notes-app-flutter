# Notes & Task Management App 📝

A modern, fast, and cross-platform mobile application for organizing tasks and managing daily notes, built using **Flutter** and **Dart**.

---

## 📱 Features

* **Task Management:** Create, track, and manage daily to-do lists effortlessly.
* **Rich Notes:** Quick note-taking with a clean and minimal user interface.
* **Responsive UI:** Smooth animations and intuitive layout designed for mobile devices.
* **State Management:** Efficient data handling across screens.

---

## 🛠️ Tech Stack & Tools

* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
* **IDE:** VS Code / Android Studio
